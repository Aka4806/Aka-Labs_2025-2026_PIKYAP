# Telegram Bot для конвертации валют

Простой Telegram бот для конвертации валют на Python.

## Функциональность

- Конвертация между различными валютами
- Поддержка популярных валют (USD, EUR, GBP, JPY, и др.)
- Два способа конвертации:
  1. Быстрая: через текстовое сообщение (`100 USD to EUR`)
  2. Пошаговая: через команду `/convert`
- Список доступных валют через `/currencies`
